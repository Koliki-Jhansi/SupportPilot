Severity Guide
🔴 Critical Severity

Major system outage or issue affecting many users. Immediate action is required.

Priority: P1

Examples: Entire system is down, company network outage, security incident.

🟠 High Severity

Important business work is blocked and urgent support is required.

Priority: P2

Examples: VPN failure before an important meeting, critical software not working.

🟡 Medium Severity

The user can continue some work, but the issue affects productivity.

Priority: P3

Examples: Software installation problem, slow system, non-critical application issue.

🟢 Low Severity

Minor issue or request with little business impact.

Priority: P4

Examples: Password reset request, minor configuration request.
